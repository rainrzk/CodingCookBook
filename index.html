About

Do you know why the table of contents can’t be part of the table of contents? Because of self-reference! And that’s pretty much the core idea behind this coding cookbook.

For a better coding experience — let’s use Python in this cookbook. This isn’t to criticize C++ or Java, but Python code is usually much easier to express ideas (while still offering good performance for most cases). We do not delve into low-level implementations in depth, as they are less important than their use within higher-level ideas.

I used to code primarily in C++. Note that data structures and algorithms are far more important than any specific programming language. Try solving problems on Codeforces, LeetCode or Luogu — or any coding platform you prefer!
